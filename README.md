# Workload Planner

Workload Planner is an application where a project manager can create and manage scrum boards and tickets, and members can assign themself to tickets and change their status. 

## Project Context
- Program: UCLL Programmeren
- Course: GIP5
- Academic Year: 2025–2026

## Features (under development)
- Project Manager:
  - CRUD operations on tickets
- Member:
  - Assign themselves to tickets
  - Update ticket status

## Technology
- Java Spring Boot
- PostgreSQL
- Docker
- Thymeleaf
